🚀 推荐启动器

HMCL 启动器

历史悠久、跨平台支持极佳的开源免费启动器。内置游戏版本自动下载与 Fabric / 钠 模组一键安装，新手首选。

✨ 高颜值选择

PCL2 启动器

界面动画丝滑、功能强大的现代化启动器。支持一键补全 Java 环境与自动整合包导入，在国内玩家中广受好评。

☕ 运行环境

Java 21 运行库

由于服务器采用 1.21+ / Paper 26.1.2 核心，需要 Java 21 才能正常运行。启动器通常支持自动检测并一键下载匹配的 JRE。

游戏操作

常用基础指令速查

进入游戏后，在聊天框中直接输入即可生效

/spawn 传送

立即返回服务器的出生点大厅与公共集市中心。

/sethome [家名] 家园

将当前脚下坐标标记为你的私人据点或木屋（支持设置多个）。

/home [家名] 家园

无论身处何方，均可快速瞬间传送回你保存的指定家园。

/tpa [玩家ID] 社交

向在线好友发起传送请求，待对方同意后即可传送到其身边。

/tpaccept 社交

同意其他玩家向你发起的传送请求。

/msg [ID] [内容] 通信

与指定在线玩家进行一对一私信密语交流，不占用公屏。
